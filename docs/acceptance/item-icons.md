# 控制台物品图鉴图标验收

## 范围与架构

将条目左侧文字标记替换为物品对应图标，保留名称、搜索、分页、收藏、执行和移除操作。中英文同步，独立运行，不要求 EID。不新增图鉴页面、解锁状态，不扩大收录范围，不推送或发布。

沿用现有目录 Model、输入 Controller 和 Presentation View，仅新增资源解析/渲染模块。图标模块接受物品类型与 ID，读取游戏资源；不决定命令、收藏或持久化行为。不迁移存档。

药丸优先检索成熟且许可明确的效果图标集；无可用集或缺项允许默认胶囊图标，禁止将 PillEffect 当作 PillColor。其他物品缺图是失败，不能以通用图标冒充通过。失败提供可辨认的缺图提示并记录一次诊断。

## 体验基线

入口为原有控制台；核心任务是通过图片和名称识别物品，选中后执行原有操作。打开、翻页、搜索和收藏均显示同一物品的同一图标。空结果保持空状态；非物品命令保留文字标记；选中/悬停继续使用卡片反馈，图标保持原色。资源失败不阻断操作，但明确标记缺图。关闭和重新打开保留原有状态语义。
