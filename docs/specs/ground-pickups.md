将既有底座开关扩展为统一地面生成。开启时：收藏品生成底座；饰品生成饰品；卡牌、符文及魂石生成对应拾取物。药丸完全保持原有行为，不修改药丸池、颜色映射或识别状态。

## 实现

沿用生成模块、设置模型和队列边界。将仅含收藏品 ID 的队列参数改为包含对象类型、ID 和拾取变体的生成请求，入队时固定。生成时按类型校验 ItemConfig，调用一次 Game:Spawn，绝不先 giveitem 再掉落。仅收藏品需要重掷/选项组属性，其他类型保留自身原生属性。

涉及双语 main.lua、collectible_pedestals.lua、既有专项测试、版本及文档。模块保留原路径以减少无关变更，内部方法命名表达完整物品范围。
