# 当前决定：恢复 Lua Shader 死亡菜单

2026-11-26 用户明确要求先恢复旧方案并说明缺陷。中文 2.5.34 / 英文 2.5.4-en.29 恢复 `content/shaders.xml` 与 Lua 晚期绘制，死亡菜单不依赖原生暂停组件。

**已知缺陷保留：Repentance+ 长按 R 重开可能渐暗异常或瞬间黑屏。** 资源会在引擎加载 Mod 时载入，关闭菜单或仅切换 Lua 开关不能消除影响。这不是对所有游戏补丁均已复现的声明，也不表示重开动画已修复。可尝试游戏菜单重新开始；需要恢复无 Shader 行为时须完整替换旧版 Mod 文件夹，避免资源残留。

下文为历史修复记录；其中“当前版本无 Shader”和旧包门禁规则已由上述决定取代。

# Rep+ 重开渐暗修复

中文 2.5.23、英文 2.5.4-en.18 移除死亡结算置顶使用的自定义直通 Shader，
死亡结算菜单回到普通绘制通道，可能被原生遗书遮挡。两个 Workshop 项目均支持
多个运行时，因此统一移除会被引擎预先加载的 Shader；Lua 运行时开关不能阻止
资源加载。R 输入逻辑、存档格式、身份和预览图保持不变。

用户于 2026-09-26 确认中文无 Shader 试验包恢复正常；英文应用相同改动并进行
双语自动回归。不得把英文自动验证或用户反馈扩写为全部运行时实机验收。

一手最小复现来自 Planetarium Chance 作者：
https://www.reddit.com/r/bindingofisaac/comments/1st4hw4/custom_shader_rendering_bug_in_patch_19716/

此前将 ACTION_RESTART 主动轮询认定为根因证据不足。此次修复依据用户对无
Shader 试验包的确认，不修改 R 轮询。其他 Mod 加载自定义 Shader 仍可能触发
同类问题。更新应完整替换 Mod 文件夹，避免旧 content/shaders.xml 残留。

标准 tools/build-workshop-mod.ps1 生成无 Shader 候选；包验证器拒绝残留的
shaders.xml。模拟覆盖菜单、光标和重开生命周期，但不模拟 GPU 原生淡出曲线。

2026-11-21 补充：中文 2.5.33 / 英文 2.5.4-en.28 与原生组件 0.2.4
候选增加 J510 死亡界面逐帧隐藏能力。只在控制台已完成绘制且处于死亡结算时
跳过一次 GameOver::Render；不修改死亡状态，关闭或漏掉 Lua 回调即恢复原生绘制。
只对已核对 SHA256、调用点、对象字段和返回 ABI 的 J510 启用；其他运行时及
未安装组件的纯 Lua 路径保持现状，不能声称它们的死亡遮挡已解决。资源包仍不含 Shader。

## J514 实机补充限制（2026-11-26）

中英文新候选在未加载原生组件时均已通过脚本执行死亡、开关与跨局场景。截图确认 Lua Shader 能盖住死亡遗书，但左下退出、右下重开按钮仍在菜单之上。关闭菜单后原生死亡界面正常恢复。本次恢复不能宣称完全消除死亡遮挡；是否带该限制发布等待用户决定。它与此前保留的 R 重开渐暗问题分别记录。

### 角落遮挡已修复

用户要求修复后发布，最终实现采用死亡专用安全区域：底部为原生提示留出 80 个逻辑像素，条目及分类按剩余高度分页，保持字号、共享命中区域和选中项；回到正常游戏时恢复原布局。J514 中英文无原生组件自动实机流程及截图复核均通过。这取代上节待决定状态，R 重开渐暗仍为已知缺陷。
