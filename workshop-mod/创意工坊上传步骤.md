# Steam 创意工坊上传步骤

## 上传前测试

1. 完全退出游戏。
2. 将整个 Mod 文件夹复制到：
   `C:\Program Files (x86)\Steam\steamapps\common\The Binding of Isaac Rebirth\mods\isaac chinese console workshop`
3. 如果 Windows 要求管理员权限，选择“继续”。
4. 启动游戏，在 MODS 菜单启用本 Mod。
5. 进入一局，确认出现一次“已加载”提示，并分别用默认 `F6`、手柄长按左摇杆（L3）测试呼出；执行 `rewind` 后确认提示不重复。
6. 至少测试：圣心一次、魂心五次、Debug 3 在次数为五时只执行一次。
7. 在正常模式抽查 `stage 1c`（下水道 I）、`stage 6d`（炼狱 II）、`stage 10a`（教堂）、`stage 11a`（宝箱层）、`stage 12`（虚空）和 `stage 13`（家）；确认名称与落点一致。
8. 在贪婪模式确认楼层跳转被拦截且给予道具仍能执行；手动输入 `stage 14` 应显示安全白名单警告且不得执行。
9. 在 Repentance 与 Repentance+ 中分别测试 EID 开关、鼠标/键盘/手柄、分页，并确认 `hlz`、`heilazhu` 都能找到黑蜡烛；安装 MCM 时改为 F7，确认 F7 替代 F6，未安装 MCM 时确认默认 F6 不变。
10. 收藏一个非 74 精选列表中的道具，确认立即出现在常用精选，重启后仍保留，取消后消失。
11. 同一进程连续重开至少 20 局，确认历史不超过 8 条、存档大小稳定、Lua 内存不持续增长。

## 上传或更新

游戏已安装官方上传工具：

`C:\Program Files (x86)\Steam\steamapps\common\The Binding of Isaac Rebirth\tools\ModUploader\ModUploader.exe`

1. 打开 `ModUploader.exe`。
2. 选择 Mod 文件夹中的 `metadata.xml`。
3. 预览图选择同目录的 `preview.png`。
4. 确认名称、说明、Lua/Tweaks 标签和 Public 可见性。
5. 首次发布后接受 Steam Workshop 协议；更新现有条目时不要建立新项目。
6. 上传成功后核对 `metadata.xml` 中的工坊 ID 仍为 `3776882944`。

## 发布前检查

- 不要上传 ZIP，上传解压后的 Mod 文件夹；
- 不要把 v1.x 的 HTA、PowerShell、CMD 或桥接 Mod 混进目录；
- 当前工坊条目 ID 为 `3776882944`；后续更新必须保留该 ID，避免创建重复条目；
- Lua 产品版本与 metadata 修订号均为 `2.5.2`；不得改变工坊 ID；
- 游戏 MODS 列表名称必须保持 ASCII `Isaac Chinese Console`；创意工坊网页标题继续使用中文；
- 更新说明应包含：MODS 列表乱码修复、可选 MCM 改键、`rewind` 提示去重和字体失败诊断；
- 工坊页面要明确标注这是本地调试/娱乐工具，不支持每日挑战和在线联机。
