# 以撒中文控制台 2.5.13｜Steam 创意工坊自包含版

这是纯 Lua 游戏内 Mod。它不需要 HTA、PowerShell、CMD、Lua 桥接 Mod 或任何站外程序，也不会打开原生调试控制台。

## 前置要求

- Windows、Linux 或 Steam Deck 的 Steam PC 版《The Binding of Isaac: Rebirth》；
- 已安装 Afterbirth+、Repentance 或 Repentance+，并允许 Lua Mod；同时支持在 Repentance+ 上使用 REPENTOGON（忏悔龙）；
- 必须进入一局游戏后使用；主菜单、每日挑战和禁用 Mod 的在线模式不可用；
- 这是调试/娱乐工具，会直接改变当前局面。使用前建议备份重要存档。

不需要修改 `options.ini`，也不要求 `EnableDebugConsole=1`。Mod 通过游戏公开的 Lua API 在后台执行命令，原生控制台不会显示。

## 创意工坊安装

1. 在 Steam 创意工坊页面点击“订阅”。
2. 启动游戏，进入“MODS”菜单。
3. 确认“Isaac Chinese Console”处于启用状态（游戏 MODS 列表使用 ASCII 名称，避免中文乱码）。
4. 开始或继续一局游戏。
5. 默认按 `F6`，或用手柄长按左摇杆（L3）约 0.5 秒打开中文控制台。

## 本地测试安装

把整个 `isaac_chinese_console_workshop` 文件夹放入对应版本的 Mods 目录：

- Repentance：游戏安装目录下的 `mods`；
- Repentance+：通常为 `文档\My Games\Binding of Isaac Repentance+\mods`。

不要只复制 `main.lua`。`resources`、`scripts`、字体和图片必须保持原目录结构。

## 操作

### 键盘

- `F6`：默认打开或关闭；安装可选的 Mod Config Menu 后可修改；MCM 也可关闭每个游戏进程首局显示的键位提示、自定义手柄收藏键，并选择普通命令执行后是否关闭界面；
- 方向键：移动分类和卡片焦点；
- `Enter`：执行当前卡片；
- `PageUp` / `PageDown`：翻页；
- `-` / `+`：修改执行次数，范围 1–99；
- `F`：收藏或取消收藏当前条目；
- `D`：当前作用说明超过两行时翻到下一页；
- `/`：进入全局搜索，支持中文名全拼/首字母、英文名、命令或 ID；搜索框聚焦时可按 `Ctrl+A` 全选；
- `C`：编辑当前卡片对应的命令；
- `Esc`：关闭菜单或退出输入状态。

### 鼠标

- 左键点击分类或卡片；
- 左键点击道具卡片给予，右键点击可移除道具本体；这不会回退已经获得的资源、生成物或一次性效果；
- 所有右侧条目都显示可点击的像素星标；空心表示未收藏，实心表示已收藏，点击星标只切换收藏而不执行条目；
- 点击顶部搜索框后可直接输入；
- 点击页码两侧醒目的 `<` / `>` 按钮翻道具页，侧栏底部 `<` / `>` 翻分类页，点击 `×` 关闭；
- 点击底部次数区域的 `−` 或 `+` 修改次数。

### 中文搜索说明

Repentance 1.7.9b 的 Lua Mod 接口只提供键盘按键状态，不会把 Windows 中文输入法的候选文字交给 Mod。因此纯创意工坊 Mod 无法直接接收 IME 组成的汉字。本版为 721 个收藏品、188 个饰品、97 个卡牌/符文和 50 个胶囊效果内置全拼和首字母索引，并继续使用原有跨分类搜索：

- 输入 `shengxin` 或 `sx` 可找到“圣心”；
- 输入 `liuhuanghuo` 或 `lhh` 可找到“硫磺火”；
- 输入 `shenshengdoupeng` 或 `ssdp` 可找到“神圣斗篷”。
- 输入 `heilazhu` 或 `hlz` 可找到“黑蜡烛”（ID 260）。
- 输入 `yuzhe`、`yz`、`k1` 或 `giveitem k1` 可找到“0-愚者”；不额外解析 `g k1` 等短命令。

索引按稳定道具 ID 构建并缓存在条目上，不依赖 EID 是否开启，也不需要外部输入工具；在英文键盘状态下即可使用。

搜索框内按 `Ctrl+A` 会全选当前搜索词；随后输入会替换全文，Backspace 或 Delete 会清空。该组合键只在搜索框聚焦时生效，不作用于手动命令框、普通菜单或游戏本身。

### 手柄

- 长按左摇杆（L3）约 0.5 秒：打开菜单；再次按 L3 可关闭；
- 十字键移动，到页首/页尾时自动跨页；
- 点按 `A`：松开时执行或给予当前条目；
- 长按 `A` 约 0.5 秒：移除当前可移除道具本体；
- `B` 返回；
- `X`：收藏或取消收藏；

手柄无法输入拼音、翻阅长说明、调整批量次数或输入手动命令；这些功能仍使用鼠标/键盘。L3 通过长按避免误触；R3 不再由本 Mod 读取。菜单打开后，十字键、确认等动作会被 Mod 接管。底部操作提示会按最后使用的鼠标、键盘或手柄自动切换。

A、B、X 在所有运行时中优先采用游戏逻辑菜单动作；仅在逻辑动作缺失时使用已验证的原始按钮后备。MCM 的“手柄收藏键”默认设为“自动”，自定义时显示原始按钮编号；清除绑定即可恢复自动识别。

“常用精选”初始为空，并按最近收藏优先显示。全部收藏品、饰品、卡牌/符文、胶囊效果和命令条目均可使用 `F`、手柄 `X` 或鼠标星标管理收藏；参数参考、输出型和安全禁用命令收藏后仍保持原限制。原有 74 个重点收藏品条目继续保留在对应分类，不再默认占用精选列表。

## 批量执行

目录中的收藏品与原有安全 `giveitem` / `spawn` 操作可以执行多次。饰品、卡牌/符文、胶囊效果以及 `debug`、`stage`、`kill`、`remove` 等条目即使把次数设置为更高，也会自动限制为一次。

批量命令每隔约 7 帧执行一次，最多 99 次。超过 20 次时界面会提示可能短暂卡顿；完成或部分完成后次数会自动恢复为 1。

## 楼层跳转安全说明

正常/困难模式提供 45 个经过确认的楼层命令，包含地下室至子宫的原版、`a/b` 变体，忏悔的下水道、污水井、矿坑、灰坑、陵墓、炼狱、尸宫，以及蓝子宫、阴间、教堂、暗室、宝箱层、虚空和家。

贪婪/更贪婪模式改用游戏公开定义的 7 个专用楼层：地下室、洞穴、深牢、子宫、阴间、商店和究极贪婪。界面会按当前模式切换列表；该模式不开放后缀组合或 `stage 8` 以上编号。

两套列表都是显式白名单，不会把楼层数字与 `a/b/c/d` 任意组合。手动输入的 `stage` 命令也必须位于当前模式的同一白名单中，否则会在进入游戏原生执行队列前被阻止。给予道具、生成资源和调试命令不受影响。

## 手动命令安全限制

为了降低恶意代码、误操作和存档损坏风险，手动输入不允许换行、分号以及以下命令：

- `lua`
- `luarun`
- `luamod`
- `achievement`
- `prof`
- `fullrestart`
- `quit`

卡片内置命令不依赖文字输入，中文输入法也不会影响正常使用。

## 常见问题

### 默认 F6 没反应或与其他 Mod 冲突

确认已经进入一局、Mod 已启用，并检查是否有其他 Mod 占用了 `F6`。安装 Mod Config Menu 后，可在 `Isaac Chinese Console → 设置` 中修改键盘呼出键、手柄收藏键，也可开关每个游戏进程首局显示的 F6 / L3 键位提示，以及选择普通命令执行后关闭或保留界面；MCM 是可选增强，不是本 Mod 的前置要求。手柄确认统一使用 `ACTION_MENUCONFIRM`，若收藏键与确认或返回冲突，确认或返回优先。还可以查看 `log.txt` 中是否出现：

```text
[Isaac Chinese Console] v2.5.8 loaded; font=...; root=...
```

### 打开后提示 FONT LOAD FAILED

Mod 会先加载当前运行时的官方中文字体，失败后再从当前 Mod 安装目录加载内置 Fusion Pixel。目录定位兼容带空格、中文和不同 Steam 库位置的路径。全部候选都失败时，英文故障页会直接显示日志位置；请提供其中带 `[Isaac Chinese Console]` 的行：

- Repentance：`文档\My Games\Binding of Isaac Repentance\log.txt`；
- Repentance+：`文档\My Games\Binding of Isaac Repentance+\log.txt`。

正常情况下 Repentance 优先使用 `resources-dlc3.zh/font/`，Repentance+ 优先使用 `resources.zh/font/`；只有官方路径失败才会启用内置回退。

### 中文显示成方框

确认 `resources/font/isaac_console_fusion10.fnt`、`isaac_console_fusion12.fnt` 及对应 PNG 都存在。不要移动或重命名字体文件。

### 中文显示成 ä、» 等乱码

2.0.1 缺少字体 Unicode 标志；2.0.2 又错误地把 `Font:Load()` 的空返回值当成加载失败；2.0.3 的自制字体在部分 1.7.9b 环境中会加载为空白。2.0.4 已改用游戏本体自带的官方中文字体。安装后请彻底退出并重新启动游戏。

### 为什么“全部收藏品”里有些条目只有 ID

Repentance 的 Lua API 对原版道具只返回 `#ITEM_NAME`、`#ITEM_DESCRIPTION` 形式的本地化键。2.4.0 起，如果同时启用了 External Item Descriptions（EID），本 Mod 会通过它公开的运行时 API 读取简体中文名称和效果；不会复制、修改或捆绑 EID 文件。

EID 不是执行命令或拼音搜索的前置条件。饰品、卡牌/符文和胶囊效果已包含静态中英文名称；未安装 EID 时，分类、全拼/首字母搜索、给予、移除和批量执行仍可独立使用。非精选收藏品的详细名称和效果仍以游戏接口及可选 EID 数据为准。长说明可点击底部作用区域或按 `D` 翻页。

### 命令执行后没有效果

部分命令只在特定房间或游戏阶段有效。先用“生成魂心”或“圣心”测试基础命令链路。如果只有楼层跳转失败，请退出当前特殊房间后重试。

### 会不会出现多余的反引号或弹出原生控制台

不会。本版本没有模拟按键、粘贴或切换窗口，也不会按下反引号键。

### 能用于每日挑战或在线联机吗

不建议，也通常无法使用。每日挑战要求关闭 Mod；Repentance+ 在线模式对 Mod 有额外限制。请只在本地单人娱乐或测试局使用。

## 隐私与网络

Mod 不访问网络、不启动外部进程、不读取 Mod 目录外的文件。它只保存收藏和最近命令到自己的 Mod 数据文件。

## 字体许可

界面使用“缝合像素 / Fusion Pixel Font”的 10px、12px 简体中文 BMFont 版本。该字体采用 SIL Open Font License 1.1，来源与保留字体名称见 `THIRD-PARTY-FONTS.md`，许可全文见 `resources/font/fusion/LICENSE-OFL`。
