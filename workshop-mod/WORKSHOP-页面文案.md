# 以撒中文控制台｜游戏内自包含版

无需站外下载，无需 PowerShell，无需打开原生控制台。

**无强制前置 Mod。** External Item Descriptions（EID）仅用于可选地补全非精选道具的中文名称与效果；Mod Config Menu（MCM）仅用于可选键盘改键、手柄收藏键、开局键位提示和普通命令执行后界面行为，不影响核心控制台独立运行。

**同一订阅支持 Repentance、Repentance+ 与 REPENTOGON（忏悔龙）。** 无需安装第二个版本；现有收藏、历史和操作方式会在更新后继续保留。

订阅并启用后，进入一局游戏默认按 **F6**，或用手柄长按左摇杆（L3）约 0.5 秒，即可打开中文分类菜单。安装 MCM 后可修改键盘呼出键、手柄收藏键、开局键位提示，以及普通命令执行后是否关闭界面；常用与强力道具优先排列，支持鼠标、键盘和手柄操作。

## 主要功能

- 中文游戏内控制面板；
- 18 个分类，包含完整饰品、卡牌/符文、胶囊效果、运行控制、命令参考和自定义命令；
- 覆盖 721 个收藏品、188 个饰品、97 个卡牌/符文和 50 个胶囊效果；
- 内置 1162 个右侧物品与命令条目及自定义命令均可收藏，常用精选按最近收藏优先；
- 生成魂心、永恒之心、金箱和随机道具；
- 调试能力，以及按当前模式切换的 45 项正常模式/7 项贪婪模式楼层安全白名单；
- `giveitem` / `spawn` 批量执行 1–99 次；
- 收录 106 个命令或命令参考条目；生命周期命令使用独立安全通道，原生控制台输出型与高风险命令会明确禁用；
- 跨分类搜索，支持中文全拼/首字母、英文名、命令和 ID；搜索框支持 `Ctrl+A` 全选；
- 鼠标点击分类、卡片、空心/实心收藏星标、翻页、搜索、次数与关闭按钮；
- 手柄支持 L3 呼出/关闭、十字键导航与自动跨页、A 点按执行、A 长按移除、X 收藏、Y 翻说明、LT/RT 按焦点翻页和 LB/RB 调整次数；
- 每个游戏进程首次打开时，空的“常用精选”会自动进入“全部收藏品”第一项，十字键无需先用键盘或鼠标激活焦点；
- 可选接入 MCM 修改键盘呼出键、手柄收藏键、开局键位提示和普通命令执行后的界面行为；未安装时保持默认操作；
- 打开菜单时隐藏游戏 HUD，关闭后自动恢复；
- 调用游戏本体官方中文字体，以原生 10/12px 字号清晰绘制；
- 当前条目详情固定显示中英文名称、作用说明和实际命令；
- 当前卡片命令联动显示与 ASCII 手动编辑；
- 不模拟按键，不弹出原生控制台，不会残留反引号；
- 不联网，不启动外部程序。

## 使用方法

1. 订阅本 Mod；
2. 在游戏 MODS 菜单启用；
3. 开始一局；
4. 默认按 `F6`，或用手柄长按左摇杆（L3）约 0.5 秒打开；
5. 方向键/鼠标选择，按 `Enter` 或手柄点按 `A` 执行；手柄长按 `A` 约 0.5 秒移除。

执行次数使用 `- / +` 调整。内置收藏品与原有安全补给可批量执行；饰品、卡牌、胶囊及内置危险或流程类命令会自动限制为一次。自定义原始命令可按当前次数执行，已知生命周期命令仍固定为一次。

## 注意

这是用于本地娱乐、构筑测试和截图录制的调试工具，会改变当前局面。请勿用于每日挑战或在线联机；重要存档建议提前备份。

遇到问题请在讨论区提供游戏版本、DLC、其他 Mod 列表和 `log.txt` 中的错误内容。

`rewind` 通过一次性的末尾 Render 回调派发，避免同帧后续 Mod 回调继续访问回溯前的玩家对象；执行次数固定为一次，并等待稳定更新后再结算。
