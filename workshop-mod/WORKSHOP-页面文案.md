# 以撒中文控制台｜游戏内自包含版

**无强制前置 Mod。**

订阅并启用后，开始一局，按 **F6** 或长按手柄左摇杆（L3）约 0.5 秒即可打开中文分类菜单。

## 核心功能

- 18 个中文分类，覆盖 721 个收藏品、188 个饰品、97 个卡牌/符文、50 个胶囊效果、106 个官方命令或参考条目，以及自定义命令；
- 全部 1162 个内置物品与命令条目均可收藏；“常用精选”按最近收藏优先显示，收藏不会改变命令权限；
- 自定义命令支持可选名称、新增、搜索、收藏、编辑、删除和历史召回；没有人为条目数量限制，完整 SaveData 受 64 KiB 安全门禁保护；
- 全部 1056 个有效官方对象内置稳定 ID、中文、英文、全拼和首字母索引，可跨分类搜索；
- 正常模式提供 45 项楼层白名单，贪婪/更贪婪模式提供 7 项；生命周期命令使用独立安全通道；
- 收藏品与安全补给可批量执行 1–99 次；不适合批量的条目自动限制为单次；
- 支持键盘、鼠标和手柄；包含焦点导航、收藏、移除、次数调整、列表翻页和多页说明；
- 按屏幕尺寸与字体实测布局；调用游戏官方中文字体，以原生 10/12px 字号绘制；
- 菜单打开时隐藏游戏 HUD；原生暂停菜单出现时暂时隐藏，继续游戏后恢复；
- 不模拟按键，不弹出原生控制台，不会残留反引号。

## 操作方式

1. 按 `F6`，或长按手柄 L3 约 0.5 秒打开或关闭菜单；
2. 使用方向键、鼠标或十字键导航；
3. 按 `Enter`、鼠标左键或手柄 A 执行；
4. 对可移除物品按鼠标右键，或长按手柄 A 约 0.5 秒移除物品本体；
5. 按 F、手柄 X 或点击星标切换收藏；LT/RT 按焦点翻页，LB/RB 调整次数，D、点击说明或手柄 Y 翻阅多页说明；
6. 按 C 编辑完整命令；输入框内可用 ↑/↓ 召回命令历史。

**移除物品不等于完整撤销。** 已经获得的硬币、钥匙、炸弹、生命、生成物、房间状态和脚本效果可能继续保留。

## 可选 Mod 集成（均非前置）

**未安装以下 Mod 时，目录、搜索、执行、收藏和自定义命令仍可独立使用。**

- **External Item Descriptions（EID）**：可补全部分额外对象的中文名称与效果；本 Mod 不复制或修改 EID 文件；
- **Mod Config Menu（MCM）**：可设置键盘呼出键、手柄收藏键、开局键位提示，以及普通命令执行后是否关闭界面；未安装时使用默认值。

## 兼容性与语言版本

同一订阅支持 Repentance、Repentance+ 与 REPENTOGON（忏悔龙），无需安装第二个运行时版本。

中文版与英文版使用相同的 F6 和 L3 呼出方式；可以同时订阅，但请只启用一个语言版本。

## 安全及使用限制

这是用于本地娱乐、构筑测试和截图录制的调试工具，会改变当前局面。请勿用于每日挑战或在线联机；重要存档建议提前备份。

本 Mod 不联网、不启动外部程序。反馈问题时，请提供游戏版本、DLC/运行时、已启用 Mod 列表和 `log.txt` 相关内容。
