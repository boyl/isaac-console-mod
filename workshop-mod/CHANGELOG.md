# 更新记录

## 2.5.17

- 新增“自定义命令”分类，可为常用命令设置可选名称，并支持搜索、收藏、执行、编辑和双重确认删除。
- 自定义条目使用稳定 ID；改名或修改命令不会丢失收藏。该分类现作为进阶原始命令透传入口，允许保存未知、第三方、输出型、高风险和参数未经校验的命令，风险由用户承担。
- 自定义命令不设置条目数量上限，仅受完整 SaveData 的 64 KiB 安全门禁约束；新增、编辑、删除和收藏变更均按事务保存，失败时完整回滚。
- 新增或编辑自定义命令时可用 `↑/↓` 召回最近执行历史；编辑召回内容后退出浏览，向下越过最新记录时恢复原草稿。
- 中英文回归覆盖重复命令定位、重启持久化、原始命令按次数执行、高风险与输出型命令保存、生命周期安全分流、容量边界及超过 256 条后的行为。

## 2.5.16

- 修复 Steam Input 将一次 LB/RB 按压跨帧继续报告为同侧 LT/RT 模拟值时，次数调整后又触发目录或内容翻页的问题。
- 同侧肩键按压由 LB/RB 取得后会保持角色所有权，直到物理按键与模拟值均释放；真正的 LT/RT 翻页保持不变。
- 中英文回归新增左右两侧、跨帧误报、目录与内容焦点及非零控制器索引覆盖。

## 2.5.15

- Steam Deck 与 Steam Input 肩键适配改为语义动作优先、具名物理按键后备；Repentance、Repentance+ 与 REPENTOGON 不再依赖单一路径。
- LB/RB 继续只调整执行次数，LT/RT 继续只按当前焦点翻页；语义动作和物理按键同帧出现时仅处理一次。
- 模拟扳机使用按下/释放双阈值锁存：按住 LT/RT 不连续翻页，松开后再次按下才翻下一页。
- 中英文回归覆盖 Steam Input 风格的纯语义肩键、模拟扳机、raw 后备及非零控制器索引；不新增设置或 SaveData 字段。

## 2.5.14

- 底部帮助改为按当前键盘、鼠标或手柄输入上下文生成，只展示真实可用的操作；搜索和命令编辑仍保留必要的文本编辑快捷键。
- 手柄 Y 可在网格多页说明中单次循环翻页；分类、单页说明、搜索和命令编辑不响应，不改变执行、收藏、次数或列表页。
- Toast 按成功、警告、失败和进度语义测量一至两行，长提示优先保留“发生什么”和“下一步”，并限制在背景与屏幕内；成功提示统一为 30 帧（约 1 秒）。
- 中英文各 88 项模拟测试、冷启动和候选包验证纳入统一门禁；不新增设置、SaveData 字段或依赖。

## 2.5.13

- 关闭该选项后，给予、移除、生成、调试、批量和手动输入等普通命令会保留当前分类、分页、选中项和命令文字；命令编辑会正常结束，队列仍禁止并发提交。
- `rewind/restart/reseed/seed/challenge/goto/stage` 等会切换运行状态的命令始终先关闭界面并释放输入，不受该选项影响。
- 将运行控制、参数限制和资源补给说明改为面向用户的作用与限制，不再展示 ItemConfig、回调、派发和生命周期等实现细节。

## 2.5.12

- 命令使用语言无关的稳定收藏键，未知或已移除命令键在加载边界清理；收藏集合与顺序保存失败时共同回滚。

## 2.5.11

- 新增集中式命令规格表和“运行控制”“命令参考”分类；官方内置命令按直接执行、参数模板、生命周期、原生控制台专用和安全禁用统一归类，中英文共享相同命令契约。
- 参数命令按 A/Enter 只显示说明，按 C 打开未全选的命令模板并将光标留在尾部；未知或第三方命令必须二次确认且只能单次执行。

- `rewind` 改为动态注册一次性的末尾 Render 派发回调，确保命令执行后同帧不再有既有 Mod Render 回调访问已失效的玩家对象；完成两个稳定更新后才结算命令状态。
- 输出依赖原生控制台的命令和 Lua、退出、成就、宏等高风险命令均显示明确禁用原因，不进入执行队列。
- 新增命令值域、生命周期、未知命令确认及中英文语义一致性回归；现有输入、收藏、SaveData 和 Workshop 身份保持不变。

- 强化关闭状态的输入隔离：界面关闭且无释放租约时，输入 Hook 完全让出游戏，不再额外探测物理按键；避免在玩家与控制器初始化阶段介入游戏输入。
- 搜索或命令框收到键盘字符、删除或 Ctrl+A 后立即切回键盘提示，不再残留 A/B 手柄说明。

- 原生暂停恢复标记只跳过 Mod 自身的首个处理帧，不再阻断游戏输入；普通界面中的 `ACTION_RESTART` 始终透传并在玩家重建前释放 Mod 瞬态输入，帧回退至新局回调之间也让出全部输入；R 重启、Rewind、Rerun 及无新局回调的帧回退均清除旧的暂停恢复、输入租约和控制器归属状态，保证原生控制器能立即重新绑定。搜索与命令框仍保留字母 R 输入，不会误触发重开。
