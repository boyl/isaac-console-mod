# 原生暂停 0.1.0

这是“以撒中文控制台 / Console UI”的可选原生暂停组件，限定支持 Steam 忏悔+ v1.9.7.17 / J460 / x86。无需 REPENTOGON。不加载 DLL 时，Mod 保持原有菜单、搜索、命令和批量操作行为，只是不自动暂停。

## 使用

1. 先安装中文控制台 2.5.24 或 Console UI 2.5.4-en.19（也接受清单中保留的上一版安装基线） 的匹配副本，并安装 PowerShell 7。
2. 将包解压到可写目录，支持中文路径。正常退出以撒，双击 `start.cmd`。启动器备份原菜单文件、安装暂停菜单，再启动游戏和加载 DLL。
3. 进入一局后按原呼出键打开菜单，游戏暂停；关闭菜单恢复。以后要使用原生暂停，每次通过此启动器启动。
4. 正常退出游戏后，双击 `restore.cmd` 恢复原菜单文件。备份在 `runs` 目录；请保留 `active-run.json` 和备份直到恢复完成，不要把含本机路径与备份的已使用包转发给别人。

英文菜单在 PowerShell 7 中运行 `./start.ps1 -Language en`。自定义游戏目录使用 `./start.ps1 -GameDirectory "实际游戏目录"`。只做预检使用 `-ValidateOnly`，不会安装或启动游戏。

启动器核验 EXE 完整 SHA-256、包文件及安装基线，不匹配时停止覆盖。Steam 或 Mod 更新后，应获取对应兼容版本；本包不强行覆盖未知版本。游戏运行时拒绝安装或恢复。

## 原有功能和发布方式

DLL 是可选组件。直接从 Steam 启动不会自动加载 DLL，游戏按无 DLL 路径运行。DLL 不写入游戏目录，退出游戏后卸载，不修改磁盘 EXE 或存档。仅更新 Workshop Lua 文件不能自动提供原生暂停；本 ZIP 是独立配套包，需要保留现有 Mod 的资源和字体。

## 实现与验证

初始化在显式入口执行，避开 DllMain 的加载器锁。MinHook 1.3.4 负责控制台输入和绘制挂钩、线程暂停和指令位置调整；Lua IAT 指针原子交换。只释放自身拥有的暂停，其他暂停保持画面控制权。失败时不卸载可能仍被跳板引用的 DLL，模块与相关资源保留至游戏退出。

原生契约 27 项断言通过，包含四线程执行期间 100 轮挂钩启停；Unicode 路径加载及非游戏目标拒绝通过；中英文菜单各 50 项暂停集成断言、完整无 DLL 双语回归及最终 Lua 5.1 编译通过。

用户已验收先前暂停原型无异常。0.1.0 改进了挂钩和加载过程，暂停业务逻辑保持一致；本版本实机结果以发布目录中独立的验收记录为准，自动测试不等同于所有设备和语言实机覆盖。
