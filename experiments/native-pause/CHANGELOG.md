
# 0.2.2 暂停输入兼容修复

- 原生更新挂钩在其他暂停接管时让出更新链。
- 配套 Lua Mod 为忏悔龙切换到官方 MC_PRE_UPDATE，不获取 DLL 暂停，避免 Esc/P 后关闭菜单仍冻结。
- 原版 Rep/Rep+ 继续使用原生组件；新版忏悔龙菜单暂停无需安装本组件。

# 0.2.1 REPENTOGON+ 适配

- 为独立的固定版本 Rep+ EXE 添加哈希白名单、暂停判断及实际游戏更新挂钩，避免控制台重置取消菜单暂停。
- 不改写 REPENTOGON 的控制台状态、输入与绘制，保留其他暂停的画面归属。
- 明确独立 EXE 目录的安装与卸载方式，新增原生 bool 的 AL 返回契约和三个后端的共享测试。

# 0.2.0 自启动与 Rep 支持

- 改为一次复制文件后随 Steam 游戏启动自动加载，无需每次执行脚本或保留额外窗口。
- 添加 Repentance 1.7.9b 的独立运行时适配，保留忏悔+ J460 支持；仅对完整 EXE 哈希匹配的版本启用。
- 打包固定版本加载器、许可证、允许列表安装与卸载入口；拒绝覆盖其他同名加载器。
- 自动测试覆盖双语言、双运行时、普通启动加载、未知 EXE 拒绝及安装事务。实机验收与自动结果分开记录。
# 0.1.0 正式化记录

- 保留原型暂停语义和 Lua 可选桥接；无 DLL 的原有行为保持。
- 从 DllMain 移出挂钩、日志与 Lua API 初始化，改为加载器调用显式初始化入口。
- 使用固定 MinHook 1.3.4 处理线程和指令位置，Lua IAT 指针使用原子比较交换。
- 使用 LoadLibraryW 和 Unicode 命令行，支持中文路径；远端模块地址按实际目标模块计算。
- 失败路径保留仍可能被引用的模块/资源，不在工作线程超时时提前释放远端参数。
- 启动/恢复提供哈希核验、原始备份复用、并发变更拒绝和失败恢复。
- 新增四线程/100轮挂钩测试、跨进程 Unicode 加载测试和9项安装事务断言。
- 构建使用本机 MSVC x86、静态 CRT 和可重复链接选项；配套包与 Workshop 负载分开。

支持版本限定为忏悔+ v1.9.7.17/J460。既有原型的用户验收与新二进制实机记录分别保留。未发布远端前，不报告 GitHub 或 Workshop 已更新。
